  🚀 快速开始

  # 进入文件夹
  cd credit_analysis_demo

  # 安装依赖
  pip install -r requirements.txt

  # 运行演示程序
  python run_demo.py

  # 或直接运行完整分析
  python credit_analysis.py

  📊 核心功能亮点

  Python部分

  - 完整分析流程：数据清洗 → EDA → 特征工程 → 模型训练 → 业务分析
  - 信贷特定特征：DTI、LTI、年龄分组、收入分组等
  - 风险指标计算：PD（违约概率）、LGD（违约损失率）、EL（预期损失）
  - 模型比较：逻辑回归 vs 随机森林，AUC对比

  SQL部分

  - 业务分析查询：客户细分、产品分析、时间序列
  - 风险监控：异常检测、风险集中度、早期预警
  - 数据质量：完整性、一致性、准确性检查
  - 性能优化：索引建议、查询调优

  🎯 学习建议

  3. 逐步深入：
    - 阶段1：掌握数据清洗和EDA
    - 阶段2：学习特征工程和模型训练
    - 阶段3：理解风险指标和业务分析
    - 阶段4：应用SQL进行复杂查询分析
  4. 结合实际工作：
    - 用自己的数据替换示例数据
    - 修改风险阈值适应业务需求
    - 添加公司特定的业务规则
