### 最终 MP4 导出规范（成果展上传硬性 + 推荐，务必遵守）
**硬性**（不满足系统拒绝上传）：容器 `.mp4`；分辨率 ≤ 横屏 **1280×720**（竖屏 720×1280）；文件 ≤ **1 GB**。
**强烈推荐**（否则提示播放风险）：H.264/AVC High、`yuv420p`；AAC-LC 48kHz 双声道 128kbps；**恒定帧率 CFR 25fps**；码率 1.5–3 Mbps（≤5）；关键帧每 2s（25fps 填 GOP 50）；**Fast Start / +faststart**；逐行。
> 注意：分镜稿里写的是 1920×1080 录制便于清晰操作，但**最终必须缩到 1280×720**再上传。录屏可用 1080p 母带，导出时按下方 ffmpeg 一键规范化到 720p。

**ffmpeg 一键规范化（横屏，母带→合规 MP4）**：
```bash
ffmpeg -i input.mp4 -vf "scale=1280:720:force_original_aspect_ratio=decrease:force_divisible_by=2,fps=25" \
  -c:v libx264 -preset medium -crf 23 -maxrate 3M -bufsize 6M -pix_fmt yuv420p \
  -g 50 -keyint_min 50 -sc_threshold 0 -fps_mode cfr \
  -c:a aac -b:a 128k -ar 48000 -af "aresample=async=1:first_pts=0" -movflags +faststart output-web.mp4
```
**上传前自检**：Chrome/Edge 直接打开，连播 1 分钟确认音画不漂移；拖到 25/50/75% 应 2 秒内恢复；总时长稳定。

# ======== 块 A · 项目框架讲解（约 40 秒，HTML 页）========

**画面**：全屏打开 `讲解视频_框架展示.html`（Chrome/Edge，1280 宽）。页面从上到下：标题+三个数字（473 客户 / 20 黑产 / 全程留痕）→ 核心数据流管线（来电→分轨判角→声纹提取→ 1:1 自核 + 1:N 黑产比对 →结论&复核）→ 四项核心能力卡。镜头随旁白从上往下缓慢移动，管线和能力卡各停一下。

**旁白**：
> 先看这套平台是做什么的。它面向电话催收场景，把一通录音变成一条可审计的风险流水线。
> 一通双声道来电进来，平台先**分轨判角**，分出客服和客户；对客户声道**提取声纹**；然后同时做两件事——**1:1 自核**确认还是不是本人，**1:N 黑产比对**看是否命中黑产名单；结论自动落库，灰区自动转人工复核。
> 归纳成四项能力：录音角色识别、客户声纹库、黑产声纹库，以及从全量客户里挖影子团伙的团伙声纹簇。目前平台已沉淀 473 个客户声纹档案、20 个黑产身份，全程脱敏。

**时间轴**：标题+数字 8s → 数据流管线 18s → 四项能力卡 12s → 过渡 2s。

**注意**：这块**只讲框架、不进平台**。技术底座（转写/声纹提取/比对）在页脚一行小字带过，旁白不展开模型。
