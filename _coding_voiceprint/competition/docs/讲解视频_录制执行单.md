# 声纹反欺诈平台 · 讲解视频录制执行单

> 照着这张单子从上到下走一遍即可。配套：分镜稿 `讲解视频_旁白与分镜稿.md`、框架页 `讲解视频_框架展示.html`、旁白 `讲解视频_旁白音频/*.mp3`。

## 一、录制前置（务必先做，约 15 分钟）

### 1. 启动平台（带 worker + 模型）
在 `_coding_voiceprint/competition` 目录，PowerShell 执行：
```powershell
. .\scripts\set_env.ps1        # 若 asrvenv 不存在，忽略其提示，用默认 python
$env:MODELSCOPE_CACHE = "D:\my_claude\反欺诈\声纹对比\ms_cache"
python src\web\app.py --port 8765
```
> bash 环境等价：`export MODELSCOPE_CACHE="/d/my_claude/反欺诈/声纹对比/ms_cache"; export PYTHONPATH="$(pwd)/src"; python src/web/app.py --port 8765`

### 2. 确认就绪
- 浏览器开 `http://127.0.0.1:8765`，用 `d02206` / 你的密码登录成功。
- 运行监控页确认 **worker_alive = true**。
- 总览页数字应为：客户模板 **474**（副文"473 个客户"）/ 黑产 **21**（副文"20 个身份"）/ 待复核 **0**。

### 3. 预跑块C 三条录音（关键——避免录屏时干等 7 分钟）
录屏**开始前**先把三条上传跑完，录的时候直接翻结果详情页。三条样本（都在 `_temp/voiceprint_sample_pack_20260822_1629/`）：

| 演示 | 上传文件 | 客户核验模式填的客户号 |
|---|---|---|
| C-1 新客户 | `unenrolled_from_10k/unknown_01_vp_47b589bf….mp3` | `demo_newcust_0001` |
| C-2 老客户 | `known_customer_alternate/known_01_170114433353_2.mp3` | `170114433353` |
| C-3 黑产命中 | `black_recordings/black_02_black_rec_08e8930e….mp3` | 任填，如 `demo_blackcheck_01` |

> 上传在"录音处理"页，选**客户核验**模式，填客户号 + 选文件 → 提交。三条排队串行处理，约 15 分钟全部完成。完成后在"任务中心"能看到 3 条 completed，点开就是各自结果详情页。

> ⚠️ 预跑会让计数临时变化（+3 客户、+3 录音、C-1 产生 1 条待复核）。这是真实操作痕迹，录屏时无妨；**若要求总览数字严格等于核准表，录完后 `git checkout -- data/processed/platform/platform_state.json` 并删 uploads/vectors 新增文件即可还原**（做法见分镜稿文末"平台状态清洁记录"）。

## 二、录制顺序（线性，配旁白）

> 每段先想好画面动作，播对应旁白 mp3 的同时操作屏幕。旁白时长见括号。可先录纯画面，后期把旁白音轨叠上去对齐。

### 块 A · 框架讲解（旁白 `A_框架.mp3`，45s）
- 全屏打开 `讲解视频_框架展示.html`。
- 镜头从上往下**缓慢移动**：标题+三数字（约8s）→ 数据流管线，在"1:1 自核 / 1:N 黑产"双节点稍停（约18s）→ 四项能力卡逐个扫（约12s）→ 轻微下滚带出页脚（约5s）。
- ⚠️ 旁白 45s 比原计划长，镜头别赶，铺满 45s。

### 块 B · 页面巡览（旁白 B1~B8，逐页切）
真开平台，按导航顺序逐页，每页画面 ≥ 对应旁白时长，鼠标点一下关键区域：

| 顺序 | 页面 | 旁白文件（时长） | 画面动作 |
|---|---|---|---|
| 1 | 运行总览 | `B1_总览.mp3`（6.6s） | 停上半部计数卡，**别下滚到"冻结后端"区** |
| 2 | 录音处理 | `B2_录音处理.mp3`（5.2s） | 指一下客户核验/黑产入库两个模式 |

| 4 | 客户声纹库 | `B4_客户库.mp3`（5.6s） | 点开一条客户看档案字段 |
| 5 | 黑产声纹库 | `B5_黑产库.mp3`（3.7s） | 扫 20 个身份列表 |

> 账号/权限/公告/**模型与阈值** 页跳过不录。

### 块 C · 三条实操（旁白 C1~C3，重头戏）
因已预跑，这里演"上传动作 + 翻结果"两段拼接即可：

**C-1 新客户 + 灰区转复核**（旁白 `C1_新客户.mp3`，27s）

- 真实结论：verified(2.75) / clear / accepted(0.823)。

**C-3 黑产命中**（旁白 `C3_黑产命中.mp3`，20s）—— 高潮

## 三、合成与导出

1. 把各段画面按上面顺序拼接（剪映/PR/OBS 均可），对应旁白音轨叠上、对齐。
2. 处理等待画面（若没预跑到位）用快进/剪辑压缩。
3. 母带导出后，用分镜稿文末 **ffmpeg 一键规范化命令**压到 720p / H.264 / CFR25 / +faststart。
4. **上传前自检**：Chrome/Edge 打开连播 1 分钟不漂移；拖 25/50/75% 两秒内恢复。

## 四、避坑速查
- 平台**无 worker 会卡 queued**——预跑前先确认 worker_alive=true。
- 上传客户核验模式 **客户号不能空**，否则报"业务参数不能为空"。
- 命中 UI 文案是 **"疑似黑产中介代办"**（内部 status=suspected），旁白说"命中"即可。
- 总览页**没有 477 录音卡**，别念 477；客户数念"四百七十多个"或看模板卡 474。
- 模型与阈值页**不录**（按"模型信息从简"）。
