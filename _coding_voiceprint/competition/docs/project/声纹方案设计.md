# 反欺诈声纹方案设计

> 版本：v0.1（方案草案，待评审）
> 日期：2026-07-23
> 目标：一套完整声纹能力——**声纹一致性**（换号/代理检测）+ **声纹画像**（性别/年龄/情绪等）
> 场景：催收录音、电话进线/外呼（多为 8kHz 中文电话）
> 现有基础：已用 3D-Speaker CAM++（声纹）+ FunASR（转写），本方案在此之上扩展

---

## 一、核心设计原则

> **一次提取，两条分析线。**
> 一段录音 → 预处理 + 提取一次声纹表征 → 分两条线消费：
> - **一致性线**：这段声音是不是某个已知的人（1:1 / 1:N / 跨通话聚类）
> - **画像线**：这个人是男是女、年龄、情绪、地域、背景音、断音（mute）、是否多人接听电话（>=2）
> 两条线共用预处理与 embedding，不各搭一套。

> **离线沉淀 + 实时只查。**（运行模式：两者都要）
> - 离线批处理：跑历史录音 → 建声纹库、沉淀声纹档案、标定阈值
> - 实时接口：新录音来 → 提 embedding → 1:N 查库 → 秒级返标签
> - 重计算（聚类、建库、画像模型）放离线；实时只做"提向量 + 查库"

---

## 二、整体架构（六层）

```
① 接入层    录音(m4a/mp3/wav, 多为8k电话)
      │
② 预处理层  转码16k单声道 → 声道分离 → VAD → 说话人分离(diarization)
      │                                  ↓ 切出「客户段」「坐席段」
③ 表征层    目标说话人段: 声纹embedding(CAM++) + 声学特征(F0/MFCC)
      │
      ├───────────────────┬────────────────────┐
④ 分析线   【一致性线】             【画像线】
          1:1验证/1:N检索/跨通话聚类   性别/年龄/情绪(本期) + 地域/合成检测(后期)
      │                                        │
⑤ 决策层   融合两条线 → 声纹档案 + 风险标签(映射 S1~S14)
      │
⑥ 存储层   声纹向量库(Milvus/Faiss) + 声纹属性宽表(StarRocks)
```

**公共地基**：③ 之前的预处理与说话人分离是两条线共用的，其中 **diarization 是本方案要补齐的关键**（此前靠"左右声道+能量VAD"硬凑，升级为 3D-Speaker 自带 diarization）。

---

## 三、预处理层（决定一切的地基）

| 步骤 | 做什么 | 工具 | 状态 |
|------|--------|------|------|
| 转码 | m4a/mp3 → 16k 单声道 | imageio-ffmpeg | ✅ 已有 convert_to_wav.py |
| 声道分离 | 分离通话双方 | soundfile | ✅ 已有 split_channels.py |
| VAD | 去静音/串音 | 能量VAD / FSMN-VAD | ✅ 已有 vad_trim.py |
| **说话人分离** | 整段切 speakerA/B | **3D-Speaker diarization** | ⭐ 本期补齐 |
| 质检 | 有效语音时长/SNR 过滤 | 自写 | ⭐ 新增 |

**质检门槛**：有效语音 <3s 或 SNR 过低的段 → 标"低置信"，不参与硬判定（规避此前"60s截取混入插话"的坑）。

---

## 四、一致性线（P1 重点，含黑产声纹库）

**目标**：判断"是不是同一个人 / 是不是已知黑产"，服务换号与代理检测。

| 能力 | 逻辑 | 输出 |
|------|------|------|
| 1:1 验证 | 两段 embedding 余弦/PLDA 打分 vs 阈值 | 是否同人 + 相似度 |
| **1:N 检索** | 待查段 vs 黑产声纹库 | 命中已知黑产 + Top-K |
| 跨通话聚类 | 一批录音两两比对聚类 | 同一人多号/多客户号(换号信号) |
| **黑产声纹库** | 已确认黑产代理声纹注册入库 | 新录音 1:N 命中即高危 |

- **模型**：CAM++（CNCeleb 中文/电话训练），已验证优于 ECAPA（客户簇 0.709→0.805）
- **打分升级**：余弦 → **PLDA**，对 8k 跨信道更稳
- **向量库**：Milvus 或 Faiss，支持实时 1:N
- **阈值标定**（有一批可标注 → 可做）：用已知同人/异人对画分布定阈值；**8k电话与高清语音分别标定**

### 黑产声纹库设计

```
声纹库条目: 声纹ID + embedding向量 + 标签(确认黑产/疑似)
          + 来源(哪通录音) + 注册时间 + 关联号码/客户号
```
- 入库来源：人工确认的代理黑产录音、命中 S4/S9 的案例
- 检索：新录音提 embedding → 库内余弦/PLDA Top-K → 超阈值命中

## 五、画像线（本期：情绪 + 性别 + 年龄）

| 属性 | 模型 | 反欺诈用途 | 可靠性(8k) | 本期 |
|------|------|-----------|:---:|:---:|
| **情绪** | **emotion2vec**(FunASR系,中文) | 施压/激动→异常维权S12;情绪轨迹 | 🟡中 | ✅ |
| **性别** | modelscope pipeline / F0 | 声纹库分桶、身份核验 | 🟢高 | ✅ |
| **年龄段** | modelscope age模型 | 与登记身份比对识别代打 | 🟡中 | ✅ |
| 地域方言 | 方言ID模型 | 与归属地比对、窝点聚集 | 🔴低 | ⏳后期(先粗粒度) |
| 合成/变声检测 | anti-spoofing | 识别AI合成音/变声器 | 🟡中 | ⏳后期 |
| 背景环境音 | 音频场景分类 | 窝点判断 | 🟡中 | ⏳后期 |

**本期三个属性都走 ModelScope（国内直连，与现有 FunASR/CAM++ 同生态）：**
- **情绪 → emotion2vec**：达摩院中文情绪 SOTA，与已装 FunASR 同生态，优先上
- **性别 → modelscope pipeline**：近乎免标定、可靠性高
- **年龄 → modelscope age**：中等可靠，作辅助信号
- **方言暂不做**：8k 窄带方言识别掉点严重，后期先做"普通话 vs 非普通话"粗粒度

## 六、决策/标签层（映射现有 S 系列）

| 声纹信号 | 映射标签 |
|----------|----------|
| 1:N 命中已知黑产声纹 | S4声音比对异常 / 确认黑产代理 |
| 同一声纹 + 多号码/客户号 | S1代理号码关联客户数≥2 / 疑似黑产-聚类风险 |
| 情绪持续激动/愤怒 + 施压话术 | S12胁迫施压 / 异常维权 |
| 性别/年龄与登记身份矛盾 | 疑似黑产-异常信息 |
| 多通同背景音+同地域(后期) | 疑似黑产-聚类风险(窝点) |
| 检测到合成/变声(后期) | 疑似黑产-异常信息 |

### 声纹档案（每个识别到的人一份，核心资产）
```
声纹ID → embedding + {性别,年龄段,主导情绪}
       + 关联号码列表 + 关联客户号列表
       + 出现通话数 + 首末出现时间
```
沉淀"这个声音是谁、什么样、绑哪些号码/客户"——换号检测与黑产库的核心。

## 七、存储层

- **声纹向量库**：Milvus / Faiss，存 embedding，支持 1:N 快检
- **声纹属性宽表**：StarRocks，存档案结构化属性（性别/年龄/情绪/关联关系）
- 与 `dws_anti_fraud_agent_label_df` 打通，声纹标签写回 S 系列

## 八、落地分期

| 期 | 内容 | 依赖/状态 |
|----|------|----------|
| **P1 地基+一致性** | 升级 diarization(3D-Speaker) + 质检 + 阈值标定 + 黑产声纹库 + 1:N检索 | 70%代码已有;需标注数据定阈值 |

## 九、可靠性边界（先说清，避免过度承诺）

- 🟢 **可硬用**：性别、同信道声纹一致性
- 🟡 **辅助参考**：年龄、粗粒度情绪、diarization、跨信道一致性(需标定)
- 🔴 **仅线索、需多证据**：地域方言(8k掉点重)、细粒度情绪、绝对阈值判同人

**所有声纹属性作为"信号"叠加，不单独定案**——沿用 0709 报告"声学+文本+业务查号"三重验证思路。

---

## 十、数据与标注（有一批可标注）

- **阈值标定**：标注一批"同人/异人"录音对 → 画相似度分布 → 定电话/高清各自阈值
- **画像评估**：标注性别/年龄/情绪真值 → 评估各模型在本场景准确率
- **暂不微调**：微调 CAM++ 需较大规模标注(数百人),数据积累到位后再做,可根治 8k 掉点
