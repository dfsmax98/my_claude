### diarize.py 用法（本次新成果）
```bash
MODELSCOPE_CACHE=./ms_cache PYTHONIOENCODING=utf-8 \
  python diarize.py <录音.mp3> --out-dir <输出目录>
```
产出：`_对话.md`(带说话人的对话稿) + `_diar.json`(句级:说话人/起止/文本) + `_spk{N}.wav`(按说话人拆分音频,供声纹比对)。
它一次给出「谁+何时+说了什么」，比纯声道分离信息量大。
> ⚠️ 注意：说话人编号（spk0/spk1）**不跨文件保持一致**，每通里谁是客户要看对话稿内容判断。

### voiceprint_campp.py 用法（本次新成果，CAM++ 声纹库）
```bash
# 1:1 验证两段是否同一人
MODELSCOPE_CACHE=./ms_cache PYTHONIOENCODING=utf-8 python voiceprint_campp.py verify a.wav b.wav
# 建库：目录下音频批量注册（id=文件名，可加 --id-prefix 区分批次）
... voiceprint_campp.py enroll <目录> black_db.pkl --id-prefix 0709_
# 1:N 检索
... voiceprint_campp.py search query.wav black_db.pkl --topk 5
# 查看库内容（不加载模型，秒回）
... voiceprint_campp.py info black_db.pkl
```
- embedding 走 FunASR `AutoModel(model='cam++')`，192 维 L2 归一化，点积即余弦。
- 库文件 `black_db.pkl` 结构：`{model, records:[{id,emb,source,added,tag,case}]}`。
- **阈值 0.50 是电话场景临时经验值**，务必按下方 task 用可标注数据重新标定。
- ⚠️ 每次 CLI 调用重载模型约 60s；批量任务在单进程内调用 `embed()`（脚本已懒加载单例）。
