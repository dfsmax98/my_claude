# 万条录音辅助声纹数据源说明

> 2026-08-22从原 `声纹对比/` 项目复制当前角色模型处理后的万条录音聚合embedding。此次操作只复制，不移动、不删除源文件。

## 数据口径

| 项目 | 数值 |
|------|---:|
| 原始批次录音 | 10,000条 |
| 完成角色识别 | 10,000条 |
| 正式准入客户embedding | 8,301条 |
| 去重身份 | 6,932个 |
| embedding维度 | 192 |
| embedding模型 | CAM++ `campp_funasr_ms` |
| 角色模型 | `role-text-v1-20260820` |

剩余1,699条录音未进入辅助embedding集合，原因包括单边有效语音、角色待复核或无有效对话。数据源名称中的“10k”表示源录音批次规模，不表示存在10,000条合格客户embedding。

## 文件位置

- 源目录：`声纹对比/data/recent_voiceprints_10k_role_text_v2/`。
- 比赛目录：`competition/data/processed/auxiliary_recent_voiceprints_10k_role_text_v2/`。
- 聚合向量：`customer_embeddings_v2.npz`。
- 数值角色结果：`role_results.json`，不包含完整ASR正文。
- 脱敏清单：`data/manifests/auxiliary_voiceprints_10k_role_text_v2.json`。

聚合NPZ包含 `recording_ids`、`identity_sha256`、客户声道、角色置信度、质量状态、角色margin、有效时长和embedding。文件属于敏感生物特征数据，继续由 `.gitignore` 排除。

## 校验结果

- 聚合NPZ共8,301条向量，维度均为192，数值全部有限。
- 向量L2范数范围为 `0.9999998808` 至 `1.0000001192`。
- 聚合向量与8,301个源 `.npy` 分片逐条完全一致，缺失、差异和额外分片均为0。
- 复制的5个文件与源文件SHA-256全部一致，总大小为23,062,683字节。
- 原旧角色链的9,888条聚合embedding已存在于 `data/processed/plda_training_customer_embeddings.npz`，但不作为当前角色模型下的首选辅助源。

## 使用约束

1. 该数据源可作为PLDA训练、AS-Norm背景库和embedding质量模型训练的候选数据。
2. 使用前必须通过 `identity_sha256` 剔除与目标验证集、测试集重叠的身份。
3. 训练、阈值校准和最终评估必须按身份隔离，不能仅按录音隔离。
4. 该数据源不是已确认客户模板库，也不是已确认黑产库，禁止直接并入两类正式声纹库。
5. 本次未重复复制8,301个单文件分片；聚合NPZ已逐条验证等价，后续统一读取聚合文件。
