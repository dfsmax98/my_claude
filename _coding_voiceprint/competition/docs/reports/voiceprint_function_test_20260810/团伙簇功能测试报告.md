# 声纹团伙簇功能测试报告

> 使用真实客户声道的独立音频片段构造可验证真值，再对全量客户质心执行无标签影子跑批。

## 测试口径

- 固定随机种子：`20260810`
- 真值团伙：5 个，规模为 `[3, 3, 4, 4, 5]`
- 团伙节点：19 个；每个节点来自同一真实说话人的不同高能量 30 秒窗口，并重新提取 CAM++ embedding
- 背景客户：200 个真实客户质心
- 图规则：达到阈值且互为 Top-K 才连边，至少 3 个节点才输出团伙簇。

## 参数选择结果

- 阈值：0.925
- 互为 Top-K：2
- 边数/簇数：6 / 1
- Pair Precision / Recall / F1：100.00% / 10.71% / 19.35%
- 团伙检出率：0.00%
- 加权纯度：100.00%
- 错误簇/碎片化团伙：0 / 0
- ARI / NMI：0.1934 / 0.9904
- 高精度功能测试：未通过；在 Precision≥95% 且错误簇为0的约束下检出 0/5 个已知团伙

## 检出率上限对照

- 最高团伙检出配置：阈值 0.875、互为Top-3
- 检出 4/5 个团伙，但 Pair Precision 仅 4.09%，错误簇 8 个
- 当前模型与聚类规则在本批数据上存在明显精度/召回冲突，不能把最高检出配置直接用于风险判定。
