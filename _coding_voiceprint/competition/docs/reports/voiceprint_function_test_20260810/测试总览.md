## 数据与隔离

- 模型：CAM++ 192维，仅使用已确认角色的客户声道
- 最终客户库：493 个客户；可做独立两通录音验证：369 个
- 黑产阈值校准身份与评估身份完全隔离；黑产入库录音与查询录音分离。
- 团伙真值由真实客户音频的互不重叠 30 秒片段构造，没有复制 embedding。
