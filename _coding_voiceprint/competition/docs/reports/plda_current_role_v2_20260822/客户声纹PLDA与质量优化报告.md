# 客户声纹 PLDA 与 embedding 质量优化报告

> 当前 971 条评估 embedding 均来自 role-text-v1-20260820 角色模型结果；本报告验证外部 cohort、独立训练 PLDA 和身份互斥 OOF 质量评分。

## 核心结论

- 裸余弦基线：EER 11.65%，Top-1 59.22%。
- 外部 AS-norm：`external_asnorm_k50` 使用 276 条独立客户向量，EER 10.38%，较裸余弦 -1.27pp，Top-1 61.44%。
- PLDA：使用 821 条、234 个独立训练身份，EER 8.69%，较裸余弦 -2.97pp，Top-1 73.73%。
- PLDA + 质量分流：保留 60.04% 样本时，EER 6.59%，较裸余弦 -5.06pp，Top-1 78.85%。
- AS-norm + 质量分流：保留 80.02% 样本时，EER 9.35%，较裸余弦 -2.30pp。
- 本轮全局最佳质量分流后端为 `plda`，保留 60.04% 样本时 EER 6.59%，较裸余弦 -5.06pp；质量分流应作为人工复核/拒识策略，不应让低分样本静默消失。
- 对照：上一轮同批 cohort AS-norm EER 为 9.75%；本轮外部 cohort 样本量较小，主要价值是验证无测试集借用的真实部署口径。

## 数据隔离与限制

- PLDA 训练集来自配置的身份隔离训练向量，源记录 8301 条，筛选后为 821 条；按身份哈希剔除了与评估集重叠的 17 条训练记录。
- 当前 PLDA 训练身份只有 234 个，训练规模偏小；本次 PLDA 数值只能作为路线验证，不能作为生产定版结论。
- PLDA 维度仅用训练身份做 5 折内部验证，从 [40, 60, 80, 100, 120] 中选择 80 维，未使用当前 971 条评估集调参。
- 外部 cohort 共 276 条、251 个身份，角色版本为 `{'role-text-v1-20260820': 276}`，并剔除 1 条重叠身份记录。
- 质量分数预测 PLDA 的 Top-1 检索是否成功，使用客户身份互斥的 5 折 OOF 生成；最终质量模型虽已导出，仍需独立冻结集复核后才能固定生产门槛。
- PLDA、AS-norm 和余弦的分数空间不同，报告阈值只对应各自后端，不能交叉复用 `0.751/0.8`。

## 上线建议

- P0：先以外部 AS-norm 替代裸余弦做候选打分，在独立冻结集重新标定阈值；保留裸余弦作为回滚与监控口径。
- P1：质量分数低于冻结门槛的样本转人工复核或只参与宽松召回，不直接注册为高可信模板。
- P1：扩充新角色模型重刷后的身份隔离重复客户向量用于 PLDA 重训，并冻结更大的 AS-norm cohort，重新评估二者融合。
- P2：补充音频级 SNR、削波率、VAD 有效占比和分段 embedding 一致性；当前质量模型主要覆盖时长、文本量、角色置信度和 cohort 可分性。
