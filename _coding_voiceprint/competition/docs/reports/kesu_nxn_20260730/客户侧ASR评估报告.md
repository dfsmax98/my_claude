## 说明

- 先转录双声道前30秒；话术差异达到高置信且符合本批右声道客户先验时直接采用。
- 30秒结果为中/低置信，或与右声道客户先验冲突时，扩展至120秒。
- 120秒仍为低置信或缺一方时，不再跑全量ASR，直接进入人工复核。
- `adaptive_roles.json` 只包含关键词计数、字符数、时长和角色结果，不包含转译文本。
- `customer_nxn_matrix.*` 为客户对客户矩阵，`agent_nxn_matrix.*` 为客服对客服矩阵。
- 低置信结果保留在全量矩阵中并标记待复核，可信子集指标见 `role_metrics.json`。
