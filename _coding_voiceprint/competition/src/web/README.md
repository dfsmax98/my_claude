# 声纹风险工作台

> 本地声纹识别平台前端和标准库HTTP API。

## 启动

```powershell
. .\scripts\set_env.ps1
python src\web\app.py --port 8765
```

浏览器访问 `http://127.0.0.1:8765`。

## 页面

- 运行总览与最近任务。
- 客户核验和黑产入库录音上传。
- 任务进度、双轨音频、双轨ASR和核验详情。
- 客户声纹库与黑产声纹库。
- N:N团伙候选运行记录。
- 客户首录、黑产模板、核验告警和团伙候选复核。
- 当前模型、质量阈值、客户1:1和黑产1:N阈值。

HTTP接口和安全边界见 `docs/声纹识别平台说明.md`。
