# 比赛项目 Agent 规则

## AI 会话记录

- Claude Code、Codex 和 Grok 在本项目中产生的每次对话，必须将用户发送的消息追加记录到 `docs/ai会话记录.md`；只记录用户输入，不记录助手回复、工具调用、系统提示或其他运行日志。
- 每条记录必须包含以下字段：`输入`、`时间`、`输入人员`。时间统一使用 `YYYY-MM-DD HH:mm:ss` 格式并以 `Asia/Shanghai` 时区记录；无法识别输入人员时填写 `未标识用户`。
- 会话记录只允许追加，不得改写或删除既有记录；文件不存在时应先创建该文件并保留 Markdown 格式。
- 记录内容仍须遵守项目安全与合规规则；密码、Token、银行卡号、身份证件号等敏感信息不得明文写入，必要时先脱敏后记录。
